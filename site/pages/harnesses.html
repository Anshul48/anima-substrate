What it does

A harness is the coding tool an agent runs inside. You should not have to switch tools to get memory, rules and a checker. ANIMA wraps the tool you already have: it hands over the task, applies the rules while the agent works, runs the same hidden checker on the result, and records the decision. The same task can go to a different harness by changing one word.
