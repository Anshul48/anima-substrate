What it does

You say what you want. Speech is turned into text on your own computer, with no cloud service, then matched to a short list of commands. The screen shows what it heard, the command it understood, a confirmation step, and the result. Starting or stopping work needs a typed confirmation, so a misheard word cannot start anything by itself.

How a command flows

  1. Heard

    The text the speech recogniser produced, for example “status”.

  2. Understood

    The command it matched, for example {"cmd":"status"}. Anything that matches nothing is refused.

  3. Confirmed

    For start and stop, you type to confirm.

  4. Result

    The answer appears on the state tree screen.
