Features / Voice

Talk to it Planned

Say what you want. Speech is turned into text on your own computer, with local Whisper.

Planned. This page says what it will do and what exists today.

What it does

You say what you want. Speech is turned into text on your own computer, with no cloud service, then matched to a short list of commands. The screen shows what it heard, the command it understood, a confirmation step, and the result. Starting or stopping work needs a typed confirmation, so a misheard word cannot start anything by itself.

How a command flows

  1. Heard

    The text the speech recogniser produced, for example “Show status.”

  2. Understood

    The command it matched, for example “show status” or “pause task 3”. Anything that matches nothing is refused and nothing runs.

  3. Confirmed

    For start and stop, you type to confirm.

  4. Result

    The answer appears on the state tree screen.

This flow is the design. It is planned.

Planned command Planned Not available yet.

anima voice voice/clips/show-status.wav --demo

What exists today

Planned. It uses faster-whisper, a local speech-to-text library, running on the CPU.

Limits

About six fixed English commands. Shown first from a recorded clip, because a microphone can fail inside WSL. The delay has not been measured.

What it will do

anima voice voice/clips/show-status.wav --demo prints what it heard ("Show status.") and then the tree. Starting or stopping a task needs a typed confirmation.
