Features / One-line install

One line to install Working today

One command sets ANIMA up in a private folder, with no admin rights, then checks which of your coding tools it can find.

Working today. You can check it yourself: the command is under “How to check it”.

What it does

You should be able to try ANIMA without a setup day. One line downloads it into a private folder and builds a small Python environment there. It does not need administrator rights and it does not touch the rest of your machine. Then one command checks which of your coding tools it can find.

Try it

One line to install Working today

curl -fsSL https://raw.githubusercontent.com/Anshul48/anima-substrate/main/install.sh | sh

Run it Working today

curl -fsSL https://raw.githubusercontent.com/Anshul48/anima-substrate/main/install.sh | sh

What the installer does, step by step

  1. Downloads ANIMA into a private folder

    Nothing is installed system-wide.

  2. Builds a small Python environment inside it

    Python 3 and git must already be on your machine.

  3. Checks your tools

    Muse Code, Claude Code and Codex are looked for, and each one found is reported. They must already be installed and logged in; ANIMA never asks for your passwords or keys.

What exists today

One line installs ANIMA into a private folder: the code, a small Python environment, a launcher, and a starter anima.yaml listing the coding tools it found. No admin rights, no passwords or keys asked.

Limits

The coding tools must already be installed and logged in. Memory setup and voice each need one network download.
