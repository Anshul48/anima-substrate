# About this copy

This folder is a copy of the recorded evidence for one small TRACE test run through ANIMA (20 questions, a hidden checker with 23 rules, nine recorded events).

The files are unchanged, so their fingerprints in `SHA256SUMS` still match. The original folder also holds the checker's own source and some deliberately broken test cards; those are left out of this copy, so the README here mentions a few files that are not present.

Before copying, the files were scanned for key-shaped or token-shaped strings. None were found. The only hits were the word "secret" inside article text and inside a checker rule name, and 64-character hexadecimal fingerprints.
