Features / One screen (SST)

One screen: the State Space Tree Next, not built yet

Every agent, task and attempt on one screen, drawn as a tree you can follow. SST stands for State Space Tree.

Not built yet. This page says what it will do and what exists today.

What it does

When several agents work at once, you end up piecing things together from separate windows. This screen puts the work on one page, as a tree. The root is the mission, the branches are tasks, and the leaves are attempts. Selecting a node shows its decision records. An escalation adds a branch.

See it

  • right (checked by the hidden checker)
  • wrong “done”, caught
  • waiting
  • memory hit

The colour is always written next to the node too, so nothing relies on colour alone.

What exists today

The recorded nine-job run exists as a decision log with 69 records, which is what the screen reads. The screen itself is not built yet.

Limits

It draws the decision log, not what a model is thinking. One computer.

What it will do

A web page. The root is the mission, the branches are tasks, the leaves are attempts coloured right, wrong or waiting. An escalation adds a branch. It first replays the recorded nine-job run, then follows a live run.

SST stands for State Space Tree. An older, separate project of ours also used the letters SST for a search that tries several fixes side by side. That is not what this page means.
