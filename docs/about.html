About ANIMA.

ANIMA is an open-source layer for the coding tools you already use: a memory, one screen and enforced rules around them.

If you use AI agents every day, you know the pain: they forget between sessions, you cannot see what several are doing, and “done” is not proof. ANIMA is for that pain. This page, and every number on this site, says what the project does today, not what it might do later.

Where the design comes from

The roles and rules are not invented for the product page. They come from how we run our own work: an architect, a manager for each project and workers with one job each, with rules enforced by a program, a hidden checker, and a log nobody can quietly edit. The pages and code on this site were produced by AI agents working under those rules, and each number on it points at a file.

The memory is TRACE

TRACE is our sister project: search that shows its work. It is public and has its own site and replay explorer.

What this site does not do

It sets no cookies, runs no trackers and loads no outside files. The pages work without JavaScript; scripts only add the copy buttons and the light and dark switch.
