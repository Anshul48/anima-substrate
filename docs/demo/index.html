Nine real bug-fixing jobs, run once and written down. Below you can see what the hidden checker decided for each job, then check the written record yourself. It all runs in your browser. Nothing is sent anywhere.

This page holds a copy of the run’s record files (decisions.jsonl and real3.log). Checking that copy now…

1The nine jobs

Each job is a real bug from a well-known open-source Python library, with a plain-English description. A small model on the laptop tries first. A hidden checker (tests the agent does not see and cannot edit) judges the result. If the checker says no, the next helper, Claude Sonnet, gets the job.

      How the check works, and how to run it yourself

      The first record says "prev":"GENESIS" (it has nothing before it). Every later record carries, as "prev", the SHA-256 fingerprint of the exact text of the record before it. Change anything in an earlier record and the next record no longer matches, so the change shows up.

      This page follows the same rule as check_chain.py in the repository, step for step. In a terminal it prints the same fingerprints and the same break:

      git clone https://github.com/Anshul48/anima-substrate
cd anima-substrate
python3 docs/evidence/flagship-run3/check_chain.py --tamper

      You need Python 3 and git. Nothing to install.

      Honest limits

      • This checks the record. It does not re-run the nine jobs. A full re-run needs access to each helper used in the run.
      • The Harness is a validated prototype for one kind of job: fix a bug, judged by hidden tests. Other kinds of job are not built yet.
      • Nine jobs in one run is a worked example, not a statistic.
      • The second helper was told the failing line, so it was an informed retry, not a blind one.
      • The libraries are public, so the agents may have seen similar fixes before.
      • We make no claim about long runs, or about leaving it alone while you are away. That is untested.
      • The seal shows the record was not changed afterwards. It cannot show that the run itself was honest.
      • The Harness code and its self-test (63 checks) are not in this repository yet, so neither can be re-run from here.
