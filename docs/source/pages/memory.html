What it does

Coding agents forget everything when a session ends. ANIMA keeps a memory of what past jobs decided and fixed: a recorded run put a past job back in front of the next prompt. Recall of a new, different job is a small preliminary test (baseline 0 hits at 0.30 on 3 held-out tasks; two tuned variants cleared 0.30 on 2 of 3). Each recalled note carries a pointer to the file it came from, so you can check a note instead of trusting it. The store behind it is TRACE.
