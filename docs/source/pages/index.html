The trouble with coding agents today

  • They forget between sessions.You fix the same bug twice and explain the same decision again.
  • You cannot see what several are doing.Work happens in separate windows, and you piece it together.
  • “Done” is not proof.An agent can say it is finished and be wrong.

What is real today, for one kind of job

We gave ANIMA's hidden checker and ladder nine real bug-fixing jobs from well-known open-source Python libraries, and wrote every decision down. Across two recorded runs: 18 jobs, 16 verified first try, 2 caught.

9

real bug-fix jobs, each with a plain-English description. The agent has to fix it.

7

right the first time. A Muse Code worker did the work and the hidden tests agreed.

2

wrong “done” answers. The hidden checker caught both and the next helper fixed them.
