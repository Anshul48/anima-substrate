The command

This is the only install route this page describes. We ran it end to end on 5 November 2026 on a Linux machine: it finished, and anima doctor then listed the coding tools it found. We have not run it on macOS or Windows from this page.

{{installbox}}

Needs git, Python 3.11 or newer, and network access to GitHub. It never uses sudo and never edits your shell startup files.

What installs today

  • A copy of this repository in a private folder (~/.anima/repo by default).
  • A small Python environment in that folder. No packages are downloaded into it.
  • A launcher, anima, and a starter anima.yaml that lists which of Muse Code, Claude Code and Codex it found on your machine.
  • A link to anima in ~/.local/bin, only if that folder already exists and is on your PATH.

What does not install

  • The coding tools. Muse Code, Claude Code and Codex must already be installed and logged in. ANIMA looks for the program and never asks for your passwords or keys.
  • The TRACE memory. It is a second step, anima memory setup, and needs the network once.
  • Voice. It needs a Python with a local speech-to-text package that you provide (see the voice page).
  • Roles and rules enforcement. This is planned and not built. No program reads that file today.
  • A system-wide install. Nothing outside the private folder is changed, apart from the optional link above.

What each adapter can do today is on the harness page. The Claude Code and Codex adapters are prototypes, and in the merged tree they are dry-run only.

What the installer does, step by step

  1. Checks git and Python

    Stops with a plain message if either is missing or Python is older than 3.11.

  2. Gets the code

    Clones the repository into the private folder, or fast-forwards an earlier clone.

  3. Builds the environment and launcher

    Nothing is installed system-wide.

  4. Looks for your tools

    Runs anima init, which writes anima.yaml. Then anima doctor checks each tool it found.
