30 seconds: check the record in your browser

Working today

A real recorded run of nine bug-fixing jobs. Press a button and your browser recomputes every fingerprint in the record, then change one character and watch the break show up. Nothing is sent anywhere.

Open the check

2 minutes: run the same check in a terminal

Working today

You need Python 3 and git. Nothing to install. The download is about 11 MB and the check takes about a second.

git clone https://github.com/Anshul48/anima-substrate cd anima-substrate python3 docs/evidence/flagship-run3/check_chain.py --tamper

What it printed when we ran it:

recorded run: CHAIN OK - 69 records, every link matches
  file fingerprint (SHA-256): acd95bf03497057c50fc050633eadeb024d1dc49dee55a236cb29f95b989bd5d
  matches the fingerprint saved at the end of the run: yes

changed one character on line 6 of a temporary copy (the original is untouched)
edited copy: CHAIN BROKEN - 69 records, line 7 does not match the line before it
  file fingerprint (SHA-256): 2773ad2824efdce0e88ebbb733641de8bf2b06932c8239f1a23bd0317ea80612

This checks the record. It does not re-run the nine jobs.

5 minutes: install ANIMA and plug in your harness

Working today Working today

  1. Install

    One line, no admin rights.

    One line to install Working today

    curl -fsSL https://raw.githubusercontent.com/Anshul48/anima-substrate/main/install.sh | sh

  2. See which of your tools it found

    It lists Muse Code, Claude Code and Codex, whichever are installed and logged in, and writes a starter anima.yaml.

    Run it Working today

    curl -fsSL https://raw.githubusercontent.com/Anshul48/anima-substrate/main/install.sh | sh

  3. Send one small bug task to Muse Code first

    Run it Working today

    anima run --task tiny-bug --harness muse

    Then change one word to try claude or codex.
